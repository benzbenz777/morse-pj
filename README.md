# morse-pj
จำลองจากโปรแกรม MorseThai 1.6.7 ที่จัดทำโดย 
Sateanpong Wongsakaenjun นักเรียนจ่าทหารเรือ รุ่นที่ 46 เหล่าสัญญาณวิทยุ

จุดประสงค์

1. เพื่อให้ iOS และ Android สามารถใช้งานโปรแกรมได้

2. เพื่อใช้เป็นสื่อสำหรับฝึกเรียนรู้และทบทวนรหัสมอร์ส

3. เพื่ออำนวยความสะดวกในการฝึกส่งและรับรหัสมอร์สได้ทุกที่ทุกเวลา

4. เพื่อจำลองการทำงานของโปรแกรม MorseThai 1.6.7 ให้มีรูปแบบการใช้งานที่ใกล้เคียงต้นฉบับ

5. เพื่อพัฒนาโปรแกรมให้ใช้งานง่าย รองรับผู้ใช้งานทุกระดับ ทั้งผู้เริ่มต้นและผู้ที่มีประสบการณ์อยู่แล้ว
